# مِهنتي

> حوّل مهارتك إلى عرض خدمة واضح يمكن للعميل اختياره.

**مِهنتي** أداة ويب عربية، باتجاه من اليمين إلى اليسار، تساعد المستقلين وأصحاب المهارات على بناء باقة خدمة مُحزّمة. تجمع الأداة مدخلات بسيطة عن المهارة والجمهور والنتيجة، ثم تُنتج عنوان العرض، والوعد، والنطاق، والمدة، والسعر المقترح، ورسالة تواصل أولى.

## ما الذي يتضمنه الإصدار الأول؟

| المجال | التنفيذ |
| --- | --- |
| مولّد العرض | صياغة متغيرة حسب المهارة والجمهور والنتيجة ونموذج البيع. |
| نماذج البيع | سباق مركز، مشروع مُحزّم، أو اشتراك شهري. |
| مخرجات البيع | وعد تجاري، قائمة تسليمات، مدة، سعر إرشادي، ورسالة للتواصل. |
| أدوات الاستخدام | نسخ سريع، تنزيل بصيغة Markdown، وحفظ محلي داخل الجلسة. |
| نموذج الدخل | هيكل Freemium مع مسارات «اكتشاف» و«محترف» و«فريق». |

## التشغيل محليًا

يتطلب المشروع Node.js وpnpm.

```bash
pnpm install
pnpm dev
```

للتأكد من السلامة قبل النشر:

```bash
pnpm run check
pnpm run build
```

## التقنية والتصميم

يعتمد المشروع على React 19 وTypeScript وVite وTailwind CSS. الهوية المختارة تحمل اسم **«غرفة القرار»**: ألوان كحلية حبرية، وبنفسجي مخصص للحظات القرار، ونعناعي لإشارات الجاهزية والقابلية للبيع، مع واجهة عربية متجاوبة.

## ملاحظة تشغيلية

اقتراحات السعر ومؤشر وضوح العرض إرشادية وليست ضمانًا للدخل أو للنتائج التجارية. تفعيل الاشتراكات الفعلية يحتاج إضافة مصادقة، تخزين سحابي، وبوابة دفع.
